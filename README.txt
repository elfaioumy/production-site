# نظام مراقبة الإنتاج

## طريقة التثبيت والتشغيل

1. تأكد من تثبيت Python 3.7 أو أحدث على جهازك
2. قم بتشغيل ملف `install_requirements.bat` لتثبيت المتطلبات
3. قم بتشغيل ملف `run_app.bat` لبدء تشغيل التطبيق
4. افتح المتصفح وانتقل إلى العنوان: http://localhost:5000

## ملاحظات هامة

- يجب تثبيت Python قبل تشغيل التطبيق
- إذا واجهت أي مشاكل في التثبيت، تأكد من إضافة Python إلى متغير PATH
- قاعدة البيانات موجودة في مجلد instance
